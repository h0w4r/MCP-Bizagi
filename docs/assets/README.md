# README visual assets

## Brand banner

`mcp-bizagi-banner.png` is original AI-generated presentation artwork, created with the built-in Image Gen tool on September 17, 2026 and refined in a second pass. It is not a product screenshot, an official Bizagi logo or evidence of a working feature. The connected process shapes suggest a letter B; the wordmark and tagline identify the project without turning the banner into a feature chart.

- Size: 2172 × 724 pixels (3:1).
- Format: RGB PNG, opaque navy backdrop for consistent light/dark theme presentation.
- Text: **MCP-Bizagi** / **Native process modeling. Connected.**
- Embedded metadata: none in the published image.
- The root README supplies alternative text and a separate text heading.

### Initial direction

Use case: logo-brand. Asset type: a polished, original GitHub README hero banner for the open-source-style developer project MCP-Bizagi.
Create a wide panoramic 3:1 banner, approximately 1800 by 600 pixels. Flat, precise, vector-like editorial design, not a photograph and not a software screenshot. A solid very dark midnight navy background, ample negative space, crisp typography, restrained electric blue and cool mint accents. The design must look excellent as a rectangular image in both light and dark GitHub themes.
Primary subject: an original compact geometric emblem constructed from rounded process-task blocks, a small decision diamond and a start/end circle connected by two elegant right-angle paths; together these suggest a subtle letter B and connected workflows. This is a branding symbol, NOT a real BPMN diagram or an explanatory infographic. The emblem should feel distinctive, intelligent, calm and professional.
Place the emblem on the left and a large beautifully typeset wordmark on the right, balanced together as one centered horizontal lockup. The exact main text is "MCP-Bizagi". Under it, much smaller, the exact line "Native process modeling. Connected." Text must be perfectly spelled and readable, with no extra words. The wordmark is bright off-white and the supporting line is a clear pale blue-gray.
Keep at least 7 percent padding to all image edges, generous spacing, clean closed silhouettes and sharp antialiased edges. No cropped letters or clipped symbol. No 3D, no mockup objects, no drop shadows, no glow, no circuit-board wallpaper, no AI brain icons, no textures, no gradients behind text, no UI panels, no diagrams full of labels, no watermark, no official Bizagi logo, no suggestion of vendor endorsement. A tasteful, quiet, premium developer-tool identity with strong readability. Render the final banner only.

### Final refinement

Refine this README brand banner into clean flat vector-style artwork. Preserve the exact existing wording, layout, wide 3:1 aspect ratio, large wordmark and connected-process B emblem. The text must remain exactly 'MCP-Bizagi' and 'Native process modeling. Connected.'. IMPORTANT CORRECTION: remove every trace of luminous bloom, glow, haze, grain, noise, clouds, texture, gradients, drop shadows, outlines around text and 3D bevels. Replace the entire backdrop with one perfectly uniform, fully opaque solid dark navy #101B2D. White/off-white typography, solid medium-blue task blocks and solid mint circle/diamond shapes, simple uniform-width blue connectors. Razor-clean, professionally typeset 2D branding. No lighting effects whatsoever. No mottled background. No transparency, no holes, no extra symbols or text. All text and emblem contours cleanly separated from the flat backdrop. Final artwork should have the visual clarity of a carefully typeset SVG wordmark on a solid-color canvas.
